# AL-ATHAR // دار الأثر — Collectible Design & Emirati Craftsmanship

A luxury editorial web experience for a UAE-based collectible design, interior décor, and unconventional furniture gallery. The platform celebrates one-of-a-kind handmade Emirati designs alongside rare imported curios from worldwide artisanal ateliers.

## ✨ Features

- **🇦🇪 Purely Emirati Identity**: Dedicated spotlight highlighting local UAE craftsmanship, materials (Jebel Hafeet fossil limestone, desert terracotta, salvaged date palm wood, vegetable-tanned camel leather, UAE sand-cast raw brass), and an instant 1-click "Made in UAE" filter.
- **🌍 Rare Global Curations**: Showcases rare collectible pieces imported from Kyoto, Milan, Provence, and Veneto.
- **Pay (Apple Pay) Direct Checkout**: Seamless, friction-free Apple Pay modal sheet with UAE delivery address selection, biometric authorization simulation, and verified order slips.
- **💬 Direct WhatsApp Concierge**: Instant ordering and bespoke inquiries with pre-formatted luxury messages routed directly to the founder for personalized white-glove coordination.
- **🛋️ "Spaces That Inspire" Interactive Mood Board**: Editorial living room canvas with interactive hotspot pins detailing featured furniture and lighting pieces.
- **🏷️ Transparent Pricing & Currency Converter**: Pricing in AED with instant conversion to USD ($) and EUR (€).
- **🚚 White Glove Delivery Across All 7 Emirates**: Dedicated delivery journey breakdown covering Dubai, Abu Dhabi, Sharjah, and all UAE regions.

## 🛠️ Tech Stack

- **React 19**
- **Vite 8**
- **Tailwind CSS v4**
- **Lucide React** (editorial iconography)
- **Google Fonts** (Cinzel, Cormorant Garamond, Plus Jakarta Sans, Pinyon Script, Amiri)

## 🚀 Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
